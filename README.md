# TaskColumn (直欄待辦 for Google Tasks)

專為 macOS 設計的原生、高效、直欄階層待辦事項管理應用程式。

---

## ✨ 核心特點 (v1.0.1 最新版)

1. **macOS 經典三直欄階層瀏覽 + 彈性視窗佈局**
   - **欄位折疊**：隨時按下 `⌘⌥S` 折疊左欄、`⌘⌥D` 折疊右欄，空間更開闊。
   - **拖曳比例**：欄位間提供互動分割條，可按住平滑拖曳調整各欄寬度比例。
   - **Notion 式全視窗專注備忘模式**：按下 `⌘⌥F` 或點選詳細欄右上角圖示，在維持主視窗尺寸不變的前提下，將第三欄詳細資料與備忘筆記放大至全視窗，提供沉浸式長文撰寫環境，按 Esc 瞬間還原三欄。
   - **拖曳重排**：左側分類清單與中間待辦事項均支援滑鼠按住拖曳（Drag & Drop）自由調整順位。
2. **Google Tasks 雲端 OAuth 2.0 同步**
   - 於偏好設定填入您的 Google Cloud 憑證，支援系統預設瀏覽器授權跳轉與本地 8089 端口自動監聽回呼，並提供手動授權碼回填雙重備援。
3. **介面字體自適應動態縮放**
   - 集中於「偏好設定」提供 80% ~ 150% 滑桿與即時預覽，支援 `⌘ +`、`⌘ -`、`⌘ 0` 快速微調。採用原生字級重繪，結構元素絕不溢出邊界。
4. **全域快捷鍵自訂**
   - 偏好設定中可自由勾選修飾鍵（`⌘`、`⌥`、`⌃`、`⇧`）與觸發按鍵，熱更新即時生效，隨處喚出快速新增浮動視窗。
5. **macOS 選單列即時掌握 (Menu Bar Extra)**
   - 頂部狀態列即時顯示今日未完成事項數量徽章（如 `✓ 3`），點擊可直接展開今日待辦並單擊打勾消項。
6. **極致原生效能 (Swift 6 + SwiftUI)**
   - 封裝體積僅 **2.9MB**，秒開、超低記憶體佔用、支援 120Hz ProMotion 與本機離線優先快取。

## ⌨️ 常用快捷鍵指南

| 快捷鍵 | 作用 |
| :--- | :--- |
| `自訂 (預設 ⌘ ⇧ A)` | **全域快速新增**（於任何全螢幕或背景視窗呼叫浮動輸入窗） |
| `⌘ + ⌥ + S` | **折疊 / 展開左側清單欄** |
| `⌘ + ⌥ + D` | **折疊 / 展開右側詳細欄** |
| `⌘ + ⌥ + F` | **第三欄備忘全視窗專注撰寫**（Notion 式放大長文，再按一次或 Esc 還原） |
| `⌘ + =` / `⌘ + -` | **放大 / 縮小字體** |
| `⌘ + 0` | **重設字體為 100%** |
| `⌘ + N` | 聚焦目前清單的快速新增欄 |
| `⌘ + R` | 立即與 Google Tasks 進行雲端同步 |
| `空白鍵 (Space)` | 切換所選待辦事項的完成狀態 |
| `Enter` | 儲存任務 / 儲存子任務 / 提交新增 |
| `Esc` | 關閉快速新增懸浮窗 / 退出專注模式 |
